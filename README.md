# The Deterministic Universe — MATLAB Code

Companion MATLAB code for the book *The Deterministic Universe*.

Each script corresponds to one chapter and follows the same three steps:

1. **The physics engine** — the equations
2. **Initial conditions** — the numbers you are meant to change
3. **Generative visual mapping** — what the equations look like

## Requirements

- MATLAB R2016b or newer

## How to run

Open any script in MATLAB and press Run. To explore, change the numbers in
section 2 ("Initial Conditions") and run it again.
